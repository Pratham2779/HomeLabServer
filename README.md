
# Self-Assembled and Configured Server
---

## Overview

This project demonstrates the design, assembly, and configuration of a **self-hosted home lab server** using repurposed PC hardware. The server provides a **cost-effective and reliable development environment**, allowing multiple personal projects to be hosted and managed securely. This project emphasizes practical skills in **hardware assembly, Linux system administration, networking, containerization, and service reliability engineering**.

---

## Features

* **Custom Hardware Assembly:**

  * Repurposed an old PC with upgraded RAM, SSD storage, cooling system, and SMPS for a stable and efficient environment.

* **Server Deployment & Configuration:**

  * Installed and maintained Ubuntu Server OS with XFCE desktop for ease of initial setup.
  * Configured **Nginx** for web services, **Docker** for containerized project management, **SSH** for secure access, and **Cloudflare Tunnel** for external access.

* **High Availability & Resilience:**

  * Implemented mechanisms for automated service recovery after power or internet outages.
  * Achieved near-zero downtime and improved service reliability for hosted projects.

* **Hands-On Learning:**

  * Gained extensive experience with Linux system administration, networking, self-hosting, Docker containerization, and server reliability.

---

## Tech Stack

* **Hardware:** PC components (RAM, SSD, Cooling, SMPS)
* **OS & Software:** Ubuntu Server, XFCE Desktop
* **Server Tools:** Nginx, Docker, SSH
* **Networking:** Cloudflare Tunnel for secure external access

---

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Pratham2779/HomeLabServer.git
   ```

2. **Follow the hardware assembly guide** in the repository to build the server (components list included).

3. **Set up Ubuntu Server** and configure necessary software: Nginx, Docker, SSH.

4. **Deploy personal projects** by containerizing each service with Docker.

5. **Optional:** Configure Cloudflare Tunnel for secure remote access.
